# Task 3 – Java Application using Gradle

## Objective

Build a simple Java application using Gradle to automate the build process and manage dependencies.

## Technologies Used

* Java
* Gradle

## Project Structure

* `src/main/java/App.java` – Main Java program
* `build.gradle` – Gradle build configuration
* `settings.gradle` – Project settings

## Build the Project

```bash
gradle build
```

## Run the Application

```bash
gradle run
```

## Expected Output

```
Hello from Gradle!
CodeAlpha DevOps Internship - Task 3
```

## Learning Outcomes

* Automated Java builds using Gradle.
* Basic dependency management.
* Understanding build automation in DevOps.
